# specback search CLI

Query specback-generated structured data (`source-map.json`, `trace.json`, `inventory.json`, `questions.json`, `drift-report.json`) without manually reading raw JSON files.

This skill is a **companion to specback**. Install it alongside the main specback skill.

## Usage

```bash
python scripts/build-search-index.py [query] [flags]
```

## Flags

| Flag | Description | Data source |
|------|-------------|-------------|
| `query` (positional) | Substring match on source unit name or path | `source-map.json` |
| `--uncovered` | List source units not covered by any spec chapter | `trace.json` |
| `--confidence 🟢/🟡/🔴` | Filter by confidence level (Phase 2 — parses spec chapter REFs) | spec chapter files |
| `--questions [open\|all]` | Show questions (default: `open`) | `questions.json` |
| `--chapter <slug>` | Show source units covered by a specific chapter | `trace.json` |
| `--role <role>` | Filter by source unit role | `source-map.json` |
| `--drift` | Show latest drift report | `drift-report.json` |
| `--specback-dir <path>` | Path to `.specback/` (default: `.specback` in cwd) | — |
| `--format text\|json` | Output format (default: `text`) | — |

## Examples

```bash
# Name/path search
python scripts/build-search-index.py "User"

# Uncovered source units
python scripts/build-search-index.py --uncovered

# Uncovered modules only
python scripts/build-search-index.py --uncovered --role module

# Chapter coverage
python scripts/build-search-index.py --chapter 03-data-model

# Role filter
python scripts/build-search-index.py --role endpoint

# Open questions
python scripts/build-search-index.py --questions open

# Drift report
python scripts/build-search-index.py --drift

# Compound filters
python scripts/build-search-index.py "payment" --confidence 🔴
python scripts/build-search-index.py --chapter 02-feature-specs --drift

# JSON output
python scripts/build-search-index.py "User" --format json

# Custom specback directory
python scripts/build-search-index.py --specback-dir /path/to/project/.specback
```

## Output fields

| Field | Meaning |
|-------|---------|
| `SRC-NNNN` | Source unit ID (auto-generated by source_map_v2) |
| `🟢/🟡/🔴` | Confidence (extracted from `<!-- REF: ... -->` markers in spec chapters) |
| `📘 <file>` | Spec chapter/section covering this unit |
| `INV-NNN` | Inventory item ID |

## Notes

- **`.specback/` must exist**: errors with exit code 2 if missing. Run specback first.
- **`--questions` without `questions.json`**: silently shows "none found". No error.
- **`--drift` without `drift-report.json`**: shows a hint to run `detect-drift.py`. No error.
- **`--role` values**: exact case-insensitive match against `source-map.json` role strings. Common values: `module`, `class`, `orm_model`, `schema`, `component`, `endpoint`, `function`, `route`.
- **Query is substring match**: `"User"` matches `User`, `UserService`, `user_repository` (case-insensitive).
- **Filters combine as AND**: `--uncovered --role module` shows only uncovered modules.
